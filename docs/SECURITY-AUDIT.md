# Events website security review

**Issue:** [#27](https://github.com/YourMagicGenie/Events-YMG-website/issues/27)  
**Reviewed:** 10 November 2026  
**Scope:** `YourMagicGenie/Events-YMG-website` and its dedicated Events Worker only.

## Production source inspection

The connected Cloudflare API confirmed that `events.ymgconsultingservices.com` is attached to the production Worker named `ymg-events-website`. The read-only Worker metadata showed no environment bindings. The deployed bundle contains code for `Referrer-Policy`, `X-Content-Type-Options` and HSTS, but no Content Security Policy or frame-denial header. Its source still references Google Fonts and the Unsplash image CDN. The currently reviewed repository source has since self-hosted both fonts and documents the Unsplash image provenance.

This is a source/configuration inspection, not a capture of the public HTTP response. The public host could not be fetched from this environment, so the exact on-wire headers, browser request trace and production form behavior remain unverified. The production Worker and DNS were not changed.

## Headers in the canonical Worker source

The Worker now wraps responses from static assets, API routes and error paths so the policy also covers responses generated by Worker code. Cloudflare documents that `_headers` rules do not apply to Worker-generated responses; applying these headers in the Worker keeps the API and HTML behavior consistent ([Cloudflare Workers Static Assets: Headers](https://developers.cloudflare.com/workers/static-assets/headers/)).

| Header | Policy | Purpose |
| --- | --- | --- |
| `Content-Security-Policy` | On HTML only; source list is defined in `src/security-headers.js` | Restricts scripts to this origin and Turnstile; allows the reviewed Unsplash hero image; denies objects and framing; keeps fonts and forms same-origin. |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | Sends only the site origin to external links and requests. |
| `X-Content-Type-Options` | `nosniff` | Prevents MIME type guessing. |
| `X-Frame-Options` | `DENY` | Keeps the site from being embedded in frames. |
| `Strict-Transport-Security` | `max-age=31536000`, only on HTTPS requests | Remembers HTTPS for this host for one year. It deliberately omits `includeSubDomains` and `preload`. |
| `Permissions-Policy` | Disables camera, microphone and geolocation | These features are not used by the Events website. |

The CSP permits Cloudflare Turnstile's script, frame and connection endpoints for the existing #10 form flow. It permits the Unsplash image origin used by the responsive hero and its connection hint. Fonts are same-origin in the current repo source. Inline styles remain allowed because the existing static pages use embedded and element-level styles; executable inline scripts and script attributes are not allowed. The Google Apps Script relay is called server-to-server by the Worker and is not added to the browser's `connect-src` list.

The production bundle inspected above still requests Google Fonts, while this policy intentionally permits only self-hosted fonts. Do not apply the policy to the old bundle by itself; publish it together with the canonical source and #25 self-hosted font assets, then verify the deployed font requests.

## Production acceptance refresh — 11 November 2026

The canonical source now serves the public custom domain through Workers Builds. Live HTTP smoke confirms CSP (HTML), DENY frame controls, nosniff, strict-origin-when-cross-origin and HTTPS HSTS on representative home/privacy/API/assets. All images/fonts are same-origin; only the configured Turnstile is a required external browser service. Owner confirms actual inquiry inbox receipt. Source UI/API strings use inquiry; historical API compatibility remains internal.

A cloud-browser DOM audit found the parent zone automatically injected Cloudflare Web Analytics outside its EU exclusion. The ordinary analytics rule API rejected an Events-only rule with maxRulesError (409). Instead, a narrow configuration rule now sets disable_rum:true only where http.host equals events.ymgconsultingservices.com. Ruleset 2d4d3f18cf9c4fd6842e0260a27c358e, rule 99bc03ac741e44ccab032c4d13e9b655. This does not change other hosts, Turnstile, security controls or compression. The existing CSP also excludes Cloudflare Insights; it was not loosened. The live browser audit in test/live-browser-audit.mjs verifies real requests, CSP events, cookies/storage and asset loading on all four routes without submitting any form. Hosted results are attached to the acceptance PR; do not equate source tests with a real screen reader or handset.

A current all-refs Git patch scan found no private-key, GitHub-token, Google-key, AWS-key or non-test relay-deployment-URL matches. Earlier review covered 69 Actions logs; current job-log review is separately recorded in the issue. Pattern scans cannot prove absence of unknown or encoded credentials.
