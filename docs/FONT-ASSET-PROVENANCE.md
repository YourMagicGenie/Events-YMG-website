# Font asset provenance

YMG Events uses **DM Sans** and **Playfair Display** typefaces from Google Fonts. The Latin and Latin Extended WOFF2 subsets are self-hosted under `dist/assets/fonts/` to avoid a render-blocking third-party stylesheet request and to support English and Italian text without requesting font files from Google on each visit. DM Sans remains a variable font for its used 400–700 weights. Playfair Display uses static 400 normal and italic files because the design uses only those weights; this avoids downloading unused variable-weight outlines.

Both typefaces are distributed under the SIL Open Font License 1.1. The unmodified license texts are included beside the font files as `OFL-dmsans.txt` and `OFL-playfairdisplay.txt`. DM Sans uses the Google Fonts CDN release v17. Playfair Display uses v40 static 400 subsets from the `fontsource/font-files` repository, pinned to commit `5a72889057f592bb0659629e38337359f94d53b2`. The font declarations retain `font-display: swap`; the Latin regular faces used by the first viewport are preloaded, while italic and extended subsets load only when needed.

The DM Sans files were downloaded from the official Google Fonts CDN on 10 November 2026; the Playfair Display files came from the pinned Fontsource repository snapshot of the Google Fonts v40 release. This repository change updates source only; it does not deploy the production Worker.
